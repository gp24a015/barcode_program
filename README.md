# バーコード商品検索Webアプリ

スマートフォンのカメラでJANコードを読み取り、Yahoo!ショッピングAPIを利用して商品情報を検索するWebアプリです。

バーコードの読み取りだけでなく、JANコードを直接入力して検索することもできます。

## 公開サイト

https://barcode-program.vercel.app/

## 概要

本アプリでは、商品のバーコード（JANコード）を利用して商品を検索します。

検索した商品名は、機械学習モデルを利用して学習データに登録された商品名へ加工することで、商品名を整理して表示します。

また、検索した商品をブラウザのローカルストレージに保存し、商品履歴として確認できます。

## 主な機能

- カメラによるJANコード読み取り
- JANコードの直接入力による検索
- Yahoo!ショッピングAPIによる商品検索
- 機械学習による商品名の加工
- 検索した商品の履歴保存
- 商品履歴の一覧表示
- 商品履歴の削除
- バーコード画像の生成
